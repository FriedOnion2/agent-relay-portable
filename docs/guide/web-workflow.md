# 网页任务流程

首页按任务进入「迁移会话」「跨设备搬运」「全文搜索」和「Skill 资产」。来源卡显示可读写、只读或目录不可用；缺失来源可直接进入当前设备目录配置。环境与操作记录仍从顶部进入，中文 / English 可随时切换。

## 迁移会话

1. 选择来源和会话，核对正文与工具历史。
2. 选择目标软件，换设备时填写目标设备上的项目目录；高级选项可展开。
3. 检查预览的保留、降级、未知与敏感信息提示，再确认写入。取消预览不写入。

双系统的原生迁移入口保留原始记录；通用转换和原生迁移使用不同的保真规则。历史正文和工具参数里的旧路径不会自动改写。

## 跨设备搬运

原设备点击「选择会话并保存」，勾选记录并保存 ZIP。复制 ZIP 或整个 storage 目录到新设备，在新设备运行 AgentRelay，再选择包并填写本机已存在的项目目录。外置包库需重新选择目录；手填 ZIP 路径指的是服务运行设备上的文件，不是浏览器上传。

原项目只作参考。默认保留原 ID，已有记录会停止；选择新 ID 可以生成独立副本，也可手动填写。预览确认后才恢复。目标软件仍需自行安装并登录。

迁移 / 对话恢复成功后，结果卡切换页面仍保留，可复制路径、复制已有续聊命令、查看目标记录或操作记录。文件写入成功后请在真实客户端核对续聊。点击「收起结果」关闭结果卡。

## 搜索与 Skill 草稿

先更新索引，再搜索；概况显示缓存记录数、思考记录数和索引文件修改时间。索引设置与高级筛选按需展开；缓存可离线阅读，不能把旧设备路径当作新设备恢复目标。

提炼候选后先核对证据、编辑正文，勾选审核并导出。导出成功可点击「把已导出草稿存为 Skill 包」：它只把成功导出的目录交给「Skill 资产」，再点击「存储 Skill」才保存 ZIP，不会安装或执行。完整规则见 [搜索与草稿](search-and-skills.md) 和 [存储与迁移](storage-and-migration.md)。
