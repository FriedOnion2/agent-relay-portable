# 本地全文搜索与 Skill 草稿

网页右上角进入「搜索与提炼」，先点击「更新索引」。搜索与提炼复用 `index/corpus.sqlite3`；只在用户要求更新时读取来源，不监听目录、不调用模型、不执行历史工具或 Skill 指令。六个内置入口、已配置双系统来源和已启用可信读取插件均可索引；已存储原生会话包另行完整校验后读取。

## 搜索

支持中文单字、双字及更长连续短词、英文完整词、中英混合词。多个词同时满足。FTS5 使用显式中文单字/双字编码，并核验原文连续词，避免 `unicode61` 不分中文及散落字片误命中。暂不支持英文词内片段、正则、任意 FTS 查询表达式、语义搜索或文件附件 OCR。

可筛选来源、项目路径包含、工具字段包含、开始和结束日期。结束日期包含当天。每页最多50项，结果显示本机记录/存储包、离线状态及截断标记。共享 Claude Code/SDK 和相同会话存储包按内容去重；打开结果可查看缓存，当前设备且根目录一致时另有「打开本机原会话」。缓存中的旧路径只作溯源，不能自动恢复或写入。

默认不保存思考内容。开启「索引思考内容」后重建，再开启「搜索思考内容」才检索/显示这部分。关闭索引思考并更新，会从所有缓存的可查询字段和 IR 中移除已保存思考，即使来源离线。此操作不是介质级安全擦除；源日志与旧备份不受影响。

更新最多10,000条/120秒；单会话正文、思考和工具参数/结果合计保留200,000字符、最多4,000轮，每轮最多256块。截断会明确标记并排除提炼。已完成的文档事务在取消后保留；时间限制在当前有界文件读取结束后检查。达到限制可选单一来源缩小扫描范围。本版不提供跨批游标处理超过单来源限制的全量语料。

增量指纹包括主文件大小/纳秒 mtime/ctime、标题与路径、Codex 标题索引、CodeBuddy manifest 引用消息和工作区索引；DSH 选择的原生世代变化也参与更新。发现正在变化的引用文件会拒绝本次文档写入。完整且可读的来源扫描才移除已删除文档；离线根目录、读取失败、取消、上限及目录权限错误保留缓存并标记离线。

## 提炼与导出

点击「提炼 Skill 草稿」。最多读取500份完整独立缓存会话、2,000个用户任务片段，每段最多64次工具调用、50,000次比较、60秒。超过序列上限的片段整段忽略。进度和取消共用后台任务；同一服务一次只执行一个索引/提炼任务。

第一版采用确定性的保守规则：抽象工具序列和允许的参数类型相同，用户请求词汇足够相似，并有至少三条独立原生会话支持。Claude Code/SDK 的共享日志、同会话存储包和同会话修改副本不重复算独立证据；只读流程可以成为候选。无模式返回空列表，不生成猜测流程。暂不使用 LLM 语义理解、任意长度子序列挖掘或自动推断任务成功，可能漏掉步骤不同的相似任务。

候选包含有效 `name`/`description`、适用条件、参数化流程、证据、结果统计、待检查项。不复制原始命令、路径、账号或参数值；这不等同于完整敏感信息检测。工具名和安全参数名称保留；其余参数被省略。结果状态：

- `nonempty`：工具返回非空且未标错，不能证明任务成功。
- `error`：工具显式报错。
- `empty`：已匹配工具返回为空。
- `unknown`：没有可配对返回，包括调用 ID 缺失。

排序分为独立会话数乘抽象步骤数，不是置信概率。证据按钮可直接查看缓存。导出 Markdown 的证据 URL 默认使用本机8745端口，服务改用其他端口时自行改链接；链接需要携带对应 index 数据后启动 AgentRelay。

候选默认未选中。先「选中并编辑」，补充触发条件、成功判据并核对失败步骤；再勾选「已编辑并审核」，填写本机存在的导出父目录，导出 `<name>/SKILL.md`。编辑正文会取消审核勾选。同名目录拒绝覆盖；修改 frontmatter 的 name 可另存。只生成草稿，不自动安装、不执行脚本。若要在其他设备带走完整 Skill，可沿用「Skill 存储」功能。

## 便携与维护

退出服务后复制完整总包，或同时复制 `storage/`、`index/` 和自行导出的草稿目录。索引使用 SQLite schema v1 和 DELETE journal，不依赖 WAL 文件；仍不可在后台任务运行时移动数据。索引保存本地正文与工具输入输出，未加密，和原生包一样应放在你选择的存储位置。

在新设备可以直接离线查缓存。旧设备来源显示离线；存储包以便携根内相对路径识别，移动后可增量读取。外置 storage 的绝对路径需在新设备重新设置。重新选择本机 Agent 目录再更新，旧根缓存保留为离线记录，绝不会被用作新设备默认恢复目录。

未知数据库 schema 拒绝读写；更新写入前先用 SQLite backup 保留原库到 `index/corpus-schema-<版本>-<时间>.sqlite3`。本版不转换未来 schema。数据库损坏时退出服务，保留 index 副本，再将原 index 文件夹改名，重启更新以重建；不要修改 user_version 冒充兼容。

源码 CLI 示例（Release 可用缓存中的 AgentRelay 可执行文件调用相同命令）：

```sh
python app/cli.py index --source workbuddy
python app/cli.py search '发布 portable' --project project --tool Read --after 2026-10-01
python app/cli.py indexed-session <结果key>
python app/cli.py extract-skills
python app/cli.py export-draft reviewed.md --directory /existing/drafts --confirm
```

`--include-thinking` 必须在 index 与 search/indexed-session 分别显式开启。CLI 提炼只输出 JSON 中的 Markdown，不落盘；导出命令未指定 `--confirm` 会拒绝写入。
