# 维护范围评估（2026-10-10）

当前优先级是迁移身份明确、真实客户端兼容证据和可维护的错误信息。按代码行数或命令数量削减功能，不能直接提高可靠性；应依据实际调用、用户任务和兼容成本决定。

## 第一档：确认未使用的内部实现

全仓核对后，删除 `normalize_cwd`、`expand`、`Turn.all_text`、`summarize_for_list`、`_title_from_conv`、`markdown_escape`、`to_markdown_blocks`、`write_default_config`、`log_dir`、`bootstrap.report` 的未使用 `verbose` 参数以及 CLI 的不可达返回。活跃的路径规范化保留在 `adapters/base.py`，仍按 Windows / POSIX 路径处理。`DEFAULT_CONFIG` 仍被端口默认值使用，保留。

`BaseAdapter.self_check` 保留。只出现一次的定义可能是插件契约、反射调用入口或供外部使用的接口；静态扫描提供候选清单，不是删除授权或零风险证明。当前清理不移除有文档的 CLI 命令或插件能力。

覆盖率数据库和 egg-info 从 Git 索引移除；生成时仍可留在本机。忽略规则及 CI 检查阻止这些产物重新提交。

## 第二档：国际化重构已实施

原有前端覆盖测试能发现部分词条遗漏，但中文原文 key 和服务端正则仍把翻译绑定到文案。这次完成稳定 key / code 的迁移，没有新增运行时依赖：

1. `tr('ui.…', params)` 使用稳定 key；中文、英文词条分别放入 `app/web/locales.zh.json` 和 `locales.en.json`。静态文字和 placeholder / title / aria-label 使用显式 `data-i18n` 属性。
2. 业务错误、警告和预览说明从产生处携带 code 和参数，仍为兼容普通字符串的 `Message`。API 保留 `error` / `notes` 等文本字段，新增 `error_message` / `notes_messages` 描述。原有异常类型和 HTTP 状态码保留。
3. 前端删除 `EN`、`EN_SERVER` 和 `EN_PATTERNS`，按 code 翻译。批量任务、后台任务、嵌套错误和操作日志保留描述；操作日志重读后仍可切换语言。未知第三方详情原样展示，会话正文、工具参数和路径不参与文案匹配。
4. CI 检查词条集合、占位符、调用参数、静态绑定与缺失 key；验证中文文案变化不会更改 code。wheel 安装检查和四平台独立包验证覆盖实际资源加载与服务端错误翻译。

收益是文案能独立修改、业务错误可检索、翻译遗漏会在检查时失败。英文模式不保证第三方错误、用户正文和旧版本操作日志变成英文；这些没有可靠的 code，不再用中文正则猜测。维护方法见 [国际化](i18n.md)。

## 第三档：保留实现，控制产品承诺

| 功能 | 当前用途 | 判断 |
|---|---|---|
| 插件 | 内置适配器之外的可信自定义读取来源 | 保留最小契约、示例和自检，暂不扩展市场、自动安装或第三方发布生态。没有使用数据，不能推断无人使用。SHA-256 固定、独立进程和超时是完整性/故障控制，不是安全沙箱。 |
| `indexed-session` | 用搜索结果 key 读取便携索引里的缓存正文，原设备目录离线时仍可使用 | 保留。它服务于换设备后的离线查看，和按本机 ID 读取的 `show` 不同；文档补上 `search → indexed-session` 的路径即可降低理解成本。 |
| `diff` | 迁移前后比较正文和结构差异 | 保留，直接帮助检查迁移损失。 |
| `health` | 临时样本的格式回归和兼容诊断 | 保留，但样本通过不能扩大为真实客户端或厂商认证。 |
| 原生导入与四平台包 | 双系统原生对话搬迁，以及目标机无 Python/Node 的便携运行 | 核心能力，保留。 |

CLI 命令数量提示帮助入口可能需要分组，但不证明每个命令都冗余。可以在文档中按“日常迁移 / 离线搜索与存储 / 诊断与扩展”组织；若未来合并命令，先提供兼容别名和弃用周期。刚发布 1.0.0 后直接删除公开命令或插件接口，会破坏现有用户脚本。

## 真实客户端验证仍需补齐

AI 参与程度、提交密度和分支名不能证明格式适配正确与否，也无需掩盖。已有真实 Codex 客户端的跨系统恢复与续聊门槛，但续聊使用本地确定性响应接口，样本是合成数据。DSH 新轮次落盘、其他 Agent 的真实客户端、附件/索引/分支边界仍需版本明确的脱敏真实样本和真人操作记录，见 [兼容状态](compatibility.md)。代码清理与翻译重构不等于完成这些验证。
